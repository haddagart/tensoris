# Adding Translations & Multilingual Documentation

We aim to make scientific deep learning documentation accessible to global research communities worldwide.

---

## 🌍 Multilingual Guidelines

ProperDocs & MaterialX support multilingual search and localization. If you wish to contribute translations:

1. **Target Language**: Specify the target language locale code (e.g. `fr`, `es`, `ar`).
2. **Translate Core Guides**: Focus on translating `index.md`, `getting-started.md`, and `causes.md`.
3. **Preserve Code Snippets**: Keep code symbols, function signatures, and Python syntax intact.
